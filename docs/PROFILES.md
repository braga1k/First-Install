# Built-in profiles — First Install 2.8

Profiles replace your current selection. They do not install apps immediately. You can add or remove apps before choosing Review & install. Existing imported profiles remain compatible.

All profiles and User profiles are the only profile buttons. User profiles offers Save current selection and Load saved profile, using portable JSON files. All eight profiles are available from All profiles. The menu shows a summary and app count; hover to see the app list.

## Notes

- Audio production adds Equalizer APO automatically through the Peace dependency. Follow audio device and restart instructions during setup.
- Some creative tools require a license or account. Inclusion in a profile does not activate a license.
- Open-source essentials uses the reviewed open-source entries; Bitwarden is in Everyday essentials, while KeePassXC is used for the open-source profile.
- Profile selection controls are unavailable while an installation queue runs.
